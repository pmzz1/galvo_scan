# 振镜扫描成像程序 使用说明

用 USB-6363 的两路模拟输出（AO）控制振镜 X/Y，一路模拟输入（AI）读取光电探测器（PD），逐点扫描并实时显示强度图。

## 一、启动
- 双击 **`运行.bat`**。
- 首次使用或换了电脑：先双击 `安装依赖.bat`，它会在本文件夹创建独立的 Python 环境 `.venv` 并安装所需的库。
- 需要电脑上已安装 **NI-DAQmx 驱动**（本机已安装 26.8 版）。

## 二、接线

| 6363 端子 | 接到 |
|---|---|
| AO 0 | X 振镜驱动器信号输入 |
| AO 1 | Y 振镜驱动器信号输入 |
| AO GND | 两个驱动器的信号地 |
| AI 0 | PD 输出 |
| AI GND | PD 地（接线选 “RSE（单端）”） |

- 端子位置：NI MAX 中右键设备 → 设备引脚。
- 噪声大时可以改用差分：PD 信号接 AI 0，PD 地接 AI 8，界面上“接线”选“差分”。

## 三、界面说明

| 区域 | 内容 |
|---|---|
| 硬件 | 选设备和通道。没检测到设备时会自动勾选“模拟模式”；接好 6363 后点“刷新”，再取消勾选模拟模式 |
| 扫描范围 | X、Y 的起始/终止电压和步长。点数 = floor(范围 ÷ 步长) + 1，下方实时显示点数、预计时间和对应角度（1 V = 2°） |
| 扫描方式 | 单向：每行都从 X 起点扫到终点；蛇形：奇数行反向扫，省掉回扫时间 |
| 稳定时间 | 每个点写入电压后等待多久再采样（ms，可以填小数，比如 0.3） |
| 换行等待 | 每行第一个点的等待时间（振镜回扫后需要更长的稳定时间） |
| 每点采样数 / 采样率 | 每个点采 N 个样再取平均。默认 10 点 @ 100 kHz（用时 0.1 ms） |
| 电压安全上限 | 任何输出电压的绝对值都不会超过它（硬件最大 10 V） |
| 定位 | 输入 X/Y 电压，点“移动到此点”后振镜斜坡移动过去；勾选“实时读数”每 0.2 s 刷新一次 PD 读数，可用于对光和找样品。也可以先在强度图上单击一点，再点“取图上点击位置” |
| 运行 | 开始扫描 / 停止 / 回零 / 保存 CSV / 保存 PNG / 扫描结束自动保存（存到 `data` 文件夹，文件名带时间） |
| 状态 | 进度、剩余时间、当前 X/Y 和光强、饱和指示（采样峰值 ≥ 1.98 V 时变红） |
| 右侧 | “强度图”标签页：坐标轴是电压，鼠标悬停显示数值，可选色标自动范围和 X/Y 等比例显示。“数据表格”标签页：所有数值，方向与图一致 |

## 四、安全措施
- 从当前位置移到起点、扫描结束回零时，都按每步 ≤ 0.05 V 缓慢移动。
- 扫描**正常结束、点停止、出错或直接关闭窗口**时，振镜都会回到 0 V，并释放 DAQ 任务。
- 参数不合法（步长 ≤ 0、超出安全上限、总点数 > 100 万）时，不会输出任何电压。

## 五、第一次上机建议
1. 先用模拟模式熟悉界面。
2. 接上 6363 但**先不接振镜**，把 AO 0 接到 AI 0，用定位面板输入几个电压，确认读数一致（注意 AI 量程是 0~2 V）。
3. 接振镜，用小范围（比如 X、Y 都是 −0.5 ~ 0.5 V、步长 0.05）扫描，确认光斑方向和图像方向一致。方向反了就交换 X/Y 通道或对调起止值。
4. 接 PD，用定位面板把光斑移到最亮处，调 LD 功率，让读数在 1.5 ~ 1.9 V 之间、不饱和。
5. 噪声大：增大每点采样数，或改用差分接法。图像拖影或行首错位：增大稳定时间或换行等待。

## 六、CSV 数据格式
```
# 振镜扫描成像数据  保存时间: ...
# X范围(V): -1 ~ 1  步长 0.1  点数 21
# ...（全部扫描参数）
Y\X,-1,-0.9,...,1          ← 第一行：X 电压
-2,1.2345,1.2401,...       ← 每行：第一列为 Y 电压，后面为 PD 平均电压
...
```
用 Python 读取：`np.genfromtxt(path, delimiter=",", comments="#", skip_header=0)`。也可以直接用 Excel、Origin 打开。

## 七、常见错误

| 错误代码 | 原因 / 处理 |
|---|---|
| −200220 | 设备名不对。在 NI MAX 中查看设备名，点“刷新”后重新选择 |
| −50103 | 资源被占用：关闭 LabVIEW 中正在运行的程序或 MAX 测试面板 |
| −200077 | 参数不被支持（例如采样率过高） |
| −200284 | 读取超时：采样率太低或每点采样数太大 |

程序崩溃时，详细信息记录在 `error.log`。
